# Kernel and boot chain

## Summary

The image uses:

- **U-Boot 2025.01** with a small A04 DTS/defconfig
- **ARM Trusted Firmware (TF-A) v2.11.0**, `PLAT=sun50i_h6`
- **ClockworkPi A04 kernel 5.10.75-sunxi64** from
  `devterm-kernel-current-cpi-a04_0.6_arm64.deb`
- Debian 13 (trixie) arm64 userland

This is a deliberate split: current Debian userland, vendor kernel for the
A04 hardware.

## Why the vendor kernel?

The A04 panel, backlight, audio codec and thermal-printer GPIO mapping are not
in mainline Linux.  The vendor patch set contains:

- the `clockwork,devterm-a04` device tree
- H6 TCON-LCD changes in `sun4i-drm`
- the CWD686/`clockwork,cpi3-lcd` 480x1280 panel description in
  `panel-simple`
- the `ocp8178-backlight` driver
- the AC200 codec and A04 audio routing
- A04 thermal-zone setup

Mainline still lacks or differs on:

- the A04 DT (the H6 DTSI exists, but the board plumbing does not)
- H6 TCON-LCD support
- the panel timings for the 480x1280 CWD686
- the OCP8178 backlight
- the AC200 codec/amplifier binding used by the vendor kernel

Forward-porting those patches to a current mainline kernel is a real project,
not a config change.  The image therefore keeps the known-working 5.10.75
kernel and isolates it from the Debian kernel packages.  `devterm-kernel-
current-cpi-a04` conflicts with `linux-image-current-sunxi64`; do not install
the Debian sunxi kernel over it.

The image also ships `/etc/apt/preferences.d/00-devterm-kernel.pref`, which
pins `linux-image-*`, `linux-headers-*`, `linux-modules-*`, `linux-dtb-*`,
`linux-image-current-sunxi64` and `linux-dtb-current-sunxi64` to priority
`-1`.  The vendor kernel and `devterm-audio-patch` are additionally held with
`apt-mark hold`.  This makes ordinary `apt update && apt upgrade` safe from
accidental kernel replacement while allowing userland updates.

## Boot chain details

### U-Boot

Vendor defconfig values retained:

```text
CONFIG_MACH_SUN50I_H6=y
CONFIG_SUNXI_DRAM_H6_DDR3_1333=y
CONFIG_DRAM_ODT_EN=y
CONFIG_MMC0_CD_PIN="PF6"
CONFIG_MMC_SUNXI_SLOT_EXTRA=2
```

Added for distro boot:

```text
CONFIG_DISTRO_DEFAULTS=y
CONFIG_SYS_BOOTM_LEN=0x4000000
CONFIG_BOOTDELAY=3
CONFIG_ENV_IS_NOWHERE=y
CONFIG_BOOTMETH_SCRIPT=y
```

The optional H6 SCP firmware is disabled by changing U-Boot's
`SUNXI_SCP_BASE` default to `0x0` for `MACH_SUN50I_H6`.  The SCP (Crust)
firmware is only needed for system suspend; it would require an OR1K
cross-toolchain and a compatible firmware blob.  BL31 provides PSCI, and the
A04 image does not suspend.  If suspend is added later, build Crust for H6 and
re-enable the SCP entry.

U-Boot is written at **8 KiB**, the H6 BootROM's SPL offset.  The MBR
partition starts at 2 MiB, so SPL/U-Boot and the filesystem never overlap.

### extlinux

U-Boot's distro boot finds `/boot/extlinux/extlinux.conf` on the ext4 root
partition:

```text
DEFAULT devterm
LABEL devterm
  LINUX /boot/Image
  FDT /boot/devterm-a04.dtb
  INITRD /boot/initrd.img
  APPEND root=LABEL=devterm-root rootfstype=ext4 rootwait rw \
         console=ttyS0,115200 console=tty0 fbcon=rotate:1 loglevel=4
```

A `/boot/boot.scr` fallback exists for diagnostics.  There is no separate FAT
boot partition.

### initramfs

The initramfs is generated by Debian's `initramfs-tools` with `MODULES=most`
and explicitly includes:

```text
panel_simple
ocp8178_bl
pwm_sun4i
```

`panel_simple` is the driver that matches `clockwork,cpi3-lcd` in the vendor
DTB.  `ocp8178_bl` is the backlight.  They are loaded before the root
filesystem is mounted, so the panel can show early boot text.

The vendor kernel's ext4 is built in; the initramfs `fsck` hook warns that it
cannot resolve `LABEL=devterm-root`, but boot proceeds and the root filesystem
is a freshly checked ext4 image.  `rootfstype=ext4` removes ambiguity for the
kernel mount.

## Display and console

The panel is a 480x1280 portrait DSI panel.  kmscon with Ly is attempted first on tty1 at 10 px, but the vendor
sun4i-drm driver lacks the dumb-buffer support kmscon requires.  The boot
wrapper falls back to Ly on the kernel VT; `fbcon=rotate:1` is used there.  The fallback 9x18 PSF2
font gives 142 columns by 26 rows.  `fbcon` uses
`CONFIG_FRAMEBUFFER_CONSOLE_ROTATION`, which is enabled.

The vendor kernel contains the panel description in `panel-simple`
(`clockwork,cpi3-lcd`) and the OCP8178 backlight driver.  The separate
`panel-cwd686` module in the package matches `cw,cwd686`; it is not the node
used by this DTB, but it is harmless and can help with variants.

## Known kernel risks

- 5.10.75 is old; it will not receive Debian kernel security updates.
- Vendor package binaries are not reproducible from this repository; they are
  downloaded from ClockworkPi's apt repository.
- The vendor DTB/panel timings may differ between A04 revisions.
- Mainline support is future work.  The long-term path is to forward-port the
  A04 DT, TCON-LCD, panel, backlight, codec and printer GPIO pieces to a
  current mainline kernel and then use Debian's arm64 kernel package.
